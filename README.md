# wesleygomes
Meu Portfolio Digital

## Estrutura

```
index.html                  home (CSS e JS embutidos)
404.html                    pagina de erro
politica-de-cookies/        politica de cookies
politica-de-privacidade/    politica de privacidade
favicon.ico, favicon-*.png,
apple-touch-icon.png        icones do navegador e do iPhone (ficam na raiz:
                            os navegadores pedem esses arquivos em /)
site.webmanifest            instalacao no celular
robots.txt, sitemap.xml,
llms.txt                    SEO e indexacao

assets/
  css/paginas.css           estilo das paginas internas (404 e politicas)
  imagens/
    hero/                   arte da hero, uma por proporcao de tela
    cta/                    arte da CTA, uma por proporcao de tela
    capas/                  capas dos projetos do portfolio
    marca/                  logo (assinatura azul)
    icones/                 icones do manifest (192, 512 e maskable)
    social/                 imagem de compartilhamento (og-image)
```
